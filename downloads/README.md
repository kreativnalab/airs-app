## How to generate

The PDF versions of the Legal Guide can be generated from the live application using browser print-to-PDF (File → Print → Save as PDF) with the print stylesheet applied.

The .docx Policy Brief templates are produced separately using the KreativaLab document toolkit and uploaded here manually after content is finalised.
